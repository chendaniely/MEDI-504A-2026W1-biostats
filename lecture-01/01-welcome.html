Get your Codespace running

Start your Codespace now, since the first start takes about 4 minutes.

  1. Go to the Codespaces page and click Open in GitHub Codespaces
  2. When VS Code opens, trust the folder
  3. Open example.qmd and render it

Today we’re only testing the Codespace. On Wednesday you’ll fork the repository and work in your own copy.
