Solutions: Extra practice: linear regression

Note

These are the solutions to the Extra practice: linear regression exercises. Try each exercise yourself before you look.

library(tidyverse)
library(tidymodels)
library(medicaldata)

opt_clean and bw_fit, made at the top of the exercise page:

opt_clean <- opt |>
  mutate(
    Birth.outcome = str_trim(Birth.outcome),
    Group = factor(Group, levels = c("C", "T"),
                   labels = c("control", "treatment"))
  ) |>
  filter(Birth.outcome == "Live birth") |>
  select(PID, Clinic, Group, Age, BMI, Birthweight, GA.at.outcome)

bw_fit <- linear_reg() |>
  fit(Birthweight ~ Group, data = opt_clean)

bw_tidy <- tidy(bw_fit, conf.int = TRUE)

Exercise 1: The same as a t-test

t.test(Birthweight ~ Group, data = opt_clean, var.equal = TRUE)

    Two Sample t-test

data:  Birthweight by Group
t = 0.50991, df = 791, p-value = 0.6103
alternative hypothesis: true difference in means between group control and group treatment is not equal to 0
95 percent confidence interval:
 -59.88793 101.91954
sample estimates:
  mean in group control mean in group treatment 
               3258.941                3237.925

The t statistic has the same size as the regression’s (the sign flips because t.test() subtracts treatment from control), and the p-value is identical. A regression with one two-level predictor is a two-sample t-test with equal variances.

Exercise 3: Check the fit

augment(bw_fit, new_data = opt_clean) |>
  ggplot(aes(x = .pred, y = .resid)) +
  geom_jitter(width = 5, alpha = 0.3) +
  geom_hline(yintercept = 0) +
  labs(x = "Fitted birth weight (g)", y = "Residual (g)")

With one two-level predictor there are only two fitted values. The residuals are skewed: a long tail of babies born much lighter than average, often preterm.
